## ✨ The Idea

**Calibre Watches** is more than just a website — it’s a **visual experience** designed to showcase luxury timepieces in a digital format.

Built with a refined **navy blue and gold theme**, the design focuses on elegance, clarity, and a premium feel — reflecting the essence of high-end watches.

This project was created as part of a **Diploma 1st Year (2nd Semester)** academic assignment for the **Web Page Designing (WPD)** subject.

---

## 🎯 What Makes It Special?

Instead of relying on frameworks or JavaScript, this project embraces simplicity:

* 💡 **Pure HTML & CSS only**
* 🎨 Carefully crafted **luxury UI design**
* 🧭 Multi-page structured navigation
* ⚡ Lightweight & fast loading
* 📱 Responsive layout principles

> The goal was to prove that even with basic tools, you can build something visually impressive.
